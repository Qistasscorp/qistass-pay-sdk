# مجموعة Postman — Qistass Pay

جرِّب الـ API مباشرة دون كتابة أي كود.

## الاستيراد

1. افتح Postman.
2. **Import** ← اسحب الملفين `qistass-pay.postman_collection.json` و`qistass-pay.postman_environment.json` معًا.
3. من القائمة أعلى يمين Postman، اختر بيئة **"Qistass Pay — بيانات التاجر"**.
4. عبّئ المتغيرات (`public_key`، `secret_key`، `merchant_number`) بمفاتيحك الحقيقية — تُحصَّل من لوحة تحكم التاجر بعد التسجيل على [pay.qistass.com/merchant/registration](https://pay.qistass.com/merchant/registration).

## الطلبات المتضمَّنة

| الطلب | الوصف |
|---|---|
| إنشاء طلب دفع | ينشئ طلبًا حقيقيًا ويعيد رابط صفحة الدفع |
| التحقق من حالة الدفع | يتحقق من حالة عملية دفع حقيقية عبر `transaction_id` |
| التحقق من توقيع الـ Webhook (مرجع) | مثال توضيحي لآلية التحقق من التوقيع فقط — لا يُرسَل فعليًا |

⚠️ **تنبيه**: طلب "إنشاء طلب دفع" ينشئ طلب دفع **حقيقيًا** على حساب التاجر الفعلي المرتبط بالمفاتيح المُدخلة. لا تُدخل مفاتيح حساب إنتاجي حقيقي إلا إذا كنت تنوي فعلًا إنشاء واختبار عملية دفع حقيقية.
